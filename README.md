## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Amina-SE/studyhub-fullstack-app.git
```

### Navigate into Project

```bash
cd studyhub-fullstack-app
```

### Install Backend Dependencies

```bash
cd server
npm install
```

### Configure Database

1. Open MySQL Workbench.
2. Create a database named:

```
studyhub
```

3. Import the SQL file located inside the **database** folder.

4. Update your `.env` file with your MySQL credentials.

Example:

```
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=studyhub
PORT=5000
```

### Start Backend

```bash
node server.js
```

### Open Frontend

Open

```
client/index.html
```

using Live Server.
